# 线性结构

## 学习顺序

1. [顺序表](./SequentialList/)：重点理解随机访问、插入删除时的数据移动和动态扩容。
2. [链表](./LinkedList/)：重点理解头结点、指针修改顺序和动态内存释放。
3. [栈](./Stack/)：分别掌握顺序栈与链栈，理解 LIFO。
4. [队列](./Queue/)：分别掌握循环队列与链队列，理解假溢出和判空/判满条件。

## 必会操作

| 结构 | 必会操作 | 关键复杂度 |
| --- | --- | --- |
| 顺序表 | 初始化、增、删、改、按位查、按值查、扩容、销毁 | 按位查 `O(1)`；插入删除 `O(n)` |
| 单链表 | 头/尾插、增、删、改、查、逆置、销毁 | 已知前驱插删 `O(1)`；查找 `O(n)` |
| 栈 | 入栈、出栈、读栈顶、判空、销毁 | 基本操作 `O(1)` |
| 队列 | 入队、出队、读队头、判空/判满、销毁 | 基本操作 `O(1)` |

完成标准不是“运行过”，而是不看参考可以手写，并能说明所有边界条件。
