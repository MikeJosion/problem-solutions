这个仓库用于两件事：

1. 系统实现 408 数据结构中的核心结构与基本操作；
2. 记录不会做、做错或值得复习的算法题。

## 推荐学习闭环

每学一个知识点，按下面顺序推进：

1. **理解定义**：能画出逻辑结构和存储结构。
2. **手写基本操作**：初始化、增、删、改、查、遍历、销毁。
3. **写复杂度**：说明最好、最坏或平均时间复杂度以及空间复杂度。
4. **做典型题**：先写思路和边界，再写代码。
5. **记录错因**：标注不会、思路错误、实现错误或边界遗漏。
6. **定期重做**：建议在第 1、3、7、14、30 天脱离答案重写。

总体范围见 [408 复习路线图](./docs/408复习路线图.md)；新增内容时按题型复制 [综合题模板](./docs/题解模板.md) 或 [文字错题模板](./docs/文字错题模板.md)。

## 代码约定

- 主要使用 C11，索引从 `0` 还是 `1` 开始必须在题解中写清楚。
- 每个基础结构尽量拆成 `.h`、`.c` 和测试入口 `main.c`。
- 动态内存必须检查申请结果，并提供释放函数。
- 至少测试：空结构、单元素、首部、尾部、中间位置和越界输入。
- 文件统一使用 UTF-8，避免中文注释乱码。

## 编译示例

进入某个包含 `CMakeLists.txt` 的目录后：

```bash
cmake -S . -B build
cmake --build build
```

也可以直接使用 GCC，例如：

```bash
gcc -std=c11 -Wall -Wextra -pedantic SequentialLink.c main.c -o sequential_list
```
