# 408 练习与错题库

这里收录 408 四门科目的知识笔记、练习题和错题，不绑定某一本教材或辅导书。

## 四科入口

| 科目 | 主要内容 | 入口 |
| --- | --- | --- |
| 数据结构 | 线性表、树、图、查找、排序等 | [进入](./数据结构/) |
| 计算机组成原理 | 数据表示、存储器、指令、CPU、总线、I/O | [进入](./计算机组成原理/) |
| 操作系统 | 进程、内存、文件系统、I/O | [进入](./操作系统/) |
| 计算机网络 | 体系结构、各层协议与网络安全基础 | [进入](./计算机网络/) |

## 每科的三类内容

```text
科目/
├── 知识笔记/    # 概念总结、公式、对比表和易混点
├── 练习题/      # 做过的教材题、真题、模拟题，可以包含代码
└── 错题集/      # 做错或蒙对的题，以文字复盘为主
```

同一道题一般只保留一份：普通练习放在 `练习题`；做错或蒙对后移入 `错题集`，不要复制出多个版本。代码题可以使用一个题目一个目录，纯文字题直接使用一个 Markdown 文件。

## 命名建议

- 练习题：`章节/题号_简短题名/README.md` 或 `章节/题号_简短题名.md`
- 文字错题：`章节/知识点_错误关键词.md`
- 知识笔记：`章节_主题.md`

文件名应该让你半年后只看名字也能知道考点，尽量不要只写“第 12 题”。
